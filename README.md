# Multi-Channel Instagram Design & Content OS

A local-first, extensible system for managing multiple Instagram channels, reusable channel-independent layouts, post generation, content monitoring, and publication workflows.

The repository is the persistent source of truth. Start with [docs/INDEX.md](docs/INDEX.md) to load only the context needed for a task.

## Current status

Phase 1 foundation. See [docs/STATUS.md](docs/STATUS.md) and [TASKS.md](TASKS.md).

pnpm install
