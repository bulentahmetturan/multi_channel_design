# QA and Feedback

Channel, layout, and post status transitions require their documented quality gates. Deterministic QA runs first; visual AI QA is reserved for uncertain or failed visual cases.

Color treatment must pass contrast, typography readability, logo visibility, layout compatibility, feed diversity, and safe-zone validation. A registry entry can pre-validate color relationships, but the final post must re-run contextual gates.

Preference learning uses explainable, reversible channel-level weights for topic, source quality, content type, recency, urgency, layout, typography behavior, and outcomes. Keep a configurable exploration rate and never retain declined article text solely for learning.
