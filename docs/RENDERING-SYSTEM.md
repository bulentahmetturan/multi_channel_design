# Rendering System

Rendering consumes a Content Profile, selected Layout Profile and template, one Channel Pack, one typography pair, assets, and a versioned Format Profile. Outputs must be reproducible from stored input and version identifiers.

After layout selection, choose one approved color combination using content structure, layout compatibility, image brightness, text density, and recent feed history. Persist the registry and combination versions in the post record. Revalidate all combination gates against the actual render.

Run deterministic checks for dimensions, overflow, minimum type, contrast, logo policy, and safe zones before visual AI QA. Save full-post and relevant feed, grid, Story, or Reels previews.
