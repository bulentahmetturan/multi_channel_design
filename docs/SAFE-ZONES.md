# Safe Zones

Format profiles are versioned facts with authoritative sources and a last-verified date. They describe canvas dimensions, critical-content and logo zones, feed preview, profile-grid crop, and Story or Reels interface exclusions.

Fail rendering when critical content or logos leave safe areas, minimum type fails, contrast fails, UI overlays collide, wrapping breaks hierarchy, or cropping creates an accidental composition. Verify current Instagram behavior from authoritative sources before adding production dimensions.
