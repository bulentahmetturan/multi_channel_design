# Layout Grammar

Layouts are channel-independent descriptions of information structure and composition. They declare supported formats, slots, capacity ranges, image needs, hierarchy, modules, safe-zone behavior, and logo behavior (`REQUIRED`, `OPTIONAL`, or `FORBIDDEN`).

Use hard constraints only for physical, factual, accessibility, or safety impossibilities. Express aesthetic suitability as soft scores. An active layout must retain its reference hash, one-time analysis, template, constraints, previews, QA report, and version.
